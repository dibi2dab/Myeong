## 1. 24절기 기준 — 香港天文台 (HKO)

| 항목 | 내용 |
| --- | --- |
| 제공 | 香港天文台 (Hong Kong Observatory) |
| 주소 | `https://www.hko.gov.hk/en/gts/astronomy/data/files/24SolarTerms_YYYY.xml` |
| 형태 | 해마다 XML 하나. `<data>` 안에 24절기 시각 |
| 사용 범위 | 2020–2027 (8년 × 24 = 192건) |
| 저장 위치 | `tests/fixtures/hko-solar-terms-2020-2027.json` |
| 다시 받기 | `npm run tools:hko` (네트워크 필요) |
| 사용 방식 | **테스트 전용 기준값.** 계산에는 쓰지 않는다. |

### ⚠️ 이 자료는 HKT(UTC+8) 기준이다

HKO 는 Naturally Hong Kong Time = **UTC+8** 이다.
한국 표준시(KST = UTC+9)와 **1시간**이 다르다.

이 차이를 빼먹으면 실제 오차가 60분으로 보인다. 처음 이 사실을 놓쳤을 때
"최대 73.43분 오차"라는 잘못된 수치가 나왔고, 1시간을 빼자 실제 잔차가 드러났다.

### 검증 결과

```
최대 오차   13.93 분   (2025년)
평균 오차    3.60 분
날짜 일치  192 / 192
```

연도별 최대 오차(분):

| 2020 | 2021 | 2022 | 2023 | 2024 | 2025 | 2026 | 2027 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 8.14 | 6.63 | 13.43 | 8.93 | 5.97 | 13.93 | 7.19 | 7.28 |

**계산에는 쓰지 않는다.** 같은 코드를 두 번 돌려 비교하면 같은 오차가 두 번 나오기 때문에
독립 기준이 필요하다. HKO 자료가 그 역할이다.

## 2. 음력 달력표 — JJonline / calendar.js 계열

| 항목 | 내용 |
| --- | --- |
| 제공 | JJonline `calendar.js` (중국어 음력 변환 표) |
| 형태 | 연도마다 16~20비트 정수 하나 (대월 비트 + 윤달 정보) |
| 사용 범위 | 1900–2100 (201개 항목) |
| 저장 위치 | `data/lunar/lunarInfo.ts` |
| 라이선스 | 원저작자의 배포 조건을 따른다. (출처 표기) |

### 왜 이 표인가

여러 음력표가 circula. 이 프로그램은 **권위 있는 설날(음력 1월 1일) 목록과 200/200 이 일치하는
표**를 골랐다. 나머지 표는 적어도 한 해가 달랐다.

검증 기준 목록: `tests/fixtures/cny-1900-2099.json` (1900–2099, 200건).

### 이 표의 성질

- **UTC+8 기준** 표다. 그래서 윤달(중기) 판정도 **UTC+8** 로 한다.
- 지원 범위는 **1900-01-31 ~ 2100-12-31** 다. 표 밖은 즉시 거절한다.
- **가짜 윤달(假閏月)** 4곳이 있다 — 1985년 1월, 2033년 8월, 2034년 1월, 2053년 1월.
  윤달 판정 한 글자가 틀어지면 그해 음력 날짜가 통째로 어긋나므로 테스트로 고정한다.

## 3. 행정구역 — cosmosfarm/korea-administrative-district

| 항목 | 내용 |
| --- | --- |
| 제공 | cosmosfarm `korea-administrative-district` |
| 버전 | 20241209 |
| 라이선스 | MIT |
| 규모 | 17개 시도 · 228개 시군구 |
| 저장 위치 | `data/regions/regions.ts` (229행) |
| 형태 | 평탄화한 배열. `sigunguListOf(sido)` 로 조회 |
| 파생 파일 | 없음. (별도 생성 없이 바로 쓸 수 있는 평탄 배열로 저장) |

### 구조화된 선택만 받는다

- **시/도 → 시/군/구** 2단계 선택이다. 자유 입력이 없다.
- **국가가 없다.** 나라를 고르는 창을 만들지 않는다. (용도 밖)
- 세종특별자치시는 시군구 목록이 비어 있다. 이 경우 시군구 선택 단계를 건너뛴다.

시도 목록 순서는 원본 순서를 따른다:
서울 · 부산 · 인천 · 대구 · 광주 · 대전 · 울산 · 세종 · 경기 · 강원특별자치도 ·
충청북도 · 충청남도 · 경상북도 · 경상남도 · 전북특별자치도 · 전라남도 · 제주특별자치도.

출생지는 **계산에는 쓰이지 않는다.** (진태양시를 보정하지 않는다는 결정의 결과다.
`docs/calculation-rules.md` §0 참조) 다만 출생 정보를 완전한 형태로 기록하기 위해 물는다.

## 4. ΔT (지구의 자전 속도 변화)

| 항목 | 내용 |
| --- | --- |
| 제공 | Espenak & Meeus, *Polynomial Expressions for Delta T* (NASA) |
| 형태 | 다항식. 연도 → ΔT 초 |
| 사용 위치 | 절기 계산의 역행성 시각 보정 |

참조값:

| 연도 | ΔT(초) |
| --- | --- |
| 1900 | −2.790 |
| 1920 | 21.200 |
| 2000 | 63.860 |
| 2026 | 75.075 |

두 가지 성질이 테스트에 반영되어 있다.

- **과거 값은 음수일 수 있다.** 1900년 전후의 음수 값은 실제 값이지 버그가 아니다.
- **단조 증가하지 않는다.** 1929 → 1930 이 실제로 0.034초 감소한다.
  그래서 연속성 테스트 허용 폭은 **2.5초** 다.

## 5. 천체 역산 — Jean Meeus

| 항목 | 내용 |
| --- | --- |
| 제공 | Jean Meeus, *Astronomical Algorithms* (2nd ed.) |
| 사용 | 태양 겉보기 황도(저정밀도 식) · 항성 위치 · 균시차 보정 |

사용하는 내용:

- **태양 겉보기 경도** — 절기 시각 계산의 근간
- **행성 섭동 보정** — 태양 위치의 세밀한 오차를 줄이기 위해 더한다
- **황도 → 실제 시각 역추적** — 이분법으로 목표 시각을 찾는다

> **주의.** 신월(朔, 초朔)은 여기서 구하지 않는다.
> 신월은 태양 위치와 다른 궤도 요소로 계산해야 하며, 태양 위치식에서 유도하면 오차가 크다.
> 음력은 §2 의 표를 쓴다.

## 6. 명리학 고전 — `《三命通會》` 외

계산 규칙의 근거는 여러 고전에서 왔지만, **한 항목에 여러 학교를 섞지 않는다.**
선택 근거와 규칙 목록은 `docs/calculation-rules.md` 에 있고,
규칙 카탈로그는 `data/rules/rules.ts` 에 있다.

| 항목 | 근거 |
| --- | --- |
| 지장간(지장간 표) | 《三命通會》의 통월(通月) 표. 본기 1.0 / 중기 0.5 / 여기 0.3 |
| 십이운성 시작 표 | 《三命通會》. 양간 순행 · 음간 역행 |
| 월령(月令) | 전승(傳勝) 규칙만으로는 유도되지 않는다. 그래서 **데이터로 저장**한다. |
| 용신·희신 | 한 규칙(`RULE_YONGSHIN_001`)을 정해 쓴다. 다른 유파를 섞지 않는다. |
| 합·충·형·파·해 | 표준 표. 대상 조합은 구조로 저장한다. |

## 7. 용어집 — 직접 정리

`data/rules/terms.ts` 의 70개 용어는 **해석 로직에서 분리된 순수 데이터**다.
용어 설명이 바뀌어도 계산 결과는 바뀌지 않는다.

용어에는 `seeAlso` 로 다른 용어를 연결한다. (화면에서 서로 이동할 수 있다)
해석은 `core/interpretation/` 이 만들고, 용어집은 **그 결과를 설명하지 않는다.**

## 8. 이 프로젝트가 쓰지 않는 것

| 항목 | 이유 |
| --- | --- |
| 외부 AI / LLM API | 계산이 아니고, 같은 입력의 결과가 달라진다 |
| 서버 API | 계산이 전부 브라우저 안에서 끝난다 |
| 무작위 생성 | 같은 입력 → 같은 결과여야 한다 |
| 서드파티 웹 분석 | 개인정보를 옮기지 않는다 |
| 서드파티 메일 라이브러리 | `email/smtp.ts` 에 직접 쓴다. (의존성 줄이기) |
| 실시간 지역시 데이터 | KST 고정 + 서머타임 4개 구간을 코드에 넣었다 |
